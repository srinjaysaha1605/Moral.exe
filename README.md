## 📌 Overview

**MORAL.EXE** is a high-tech psychological probing environment that subjects users to 10 sequential, high-tension moral dilemmas. Powered by Google's **Gemini 3.6 Flash** engine, the system adaptively generates dynamic scenarios, measures user choices against normalized behavioral vectors, detects logical contradictions across responses, and compiles an archetypal profile report.

---

## ✨ Key Features

- 🎯 **13 Specialized Probes**: Includes probes on automated triage, autonomous vehicle ethics, systemic resource allocation, surveillance trade-offs, and algorithmic justice.
- ⚡ **Dynamic Scenario Engine**: Generates contextually unique scenarios powered by Gemini 3.6 Flash with automatic multi-model fallback.
- 🧮 **Contradiction Detection**: Calculates behavioral friction and highlights inconsistencies across user decisions.
- 📊 **Psychological Archetyping**: Maps response vectors into distinct moral archetypes (Utilitarian Optimizers, Deontological Guardians, Pragmatic Egoists, etc.).
- 🎲 **Randomized Quick-Start**: Jump directly into a randomized experiment directly from the home terminal.
- 🎨 **Dark Cyberpunk UI**: Minimalist black/red terminal aesthetic styled with Tailwind CSS, Lucide icons, and React Icons.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS, Motion, Lucide React, React Icons
- **Backend**: Express.js, Node.js (bundled with `esbuild`)
- **AI Core**: `@google/genai` (Gemini 3.6 Flash / 3.x series)
- **Deployment**: Production-ready for **Railway**, **Cloud Run**, **Render**, or **Vercel**
